# 1975_roadstory

CS171 Lab 5 scrollytelling piece: a SvelteKit + Scrollama story on U.S. road deaths, 1975-2024 (count of deaths vs. deaths per 100 million vehicle-miles).

Live site: https://ishanku.github.io/1975_roadstory/

- lab5/road-story: the app (npm install, then npm run dev)
- lab5/data: source CSVs and data README

Data: NHTSA FARS (deaths), FHWA (vehicle-miles), U.S. Census (population). The 2024 row is preliminary.
